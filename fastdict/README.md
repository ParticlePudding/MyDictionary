# fastdict

Rust + windows-rs(Win32 標準コントロール)+ SQLite(静的リンク)の個人用辞書。
起動が速く、入力中に絞り込めることを重視しています。

## 使い方
画面は「上段: 検索・辞書・操作」「左: 一覧」「右: 詳細カード」の構成です。

- **呼び出し**: ホットキー(既定 `Ctrl+Alt+D`)。Esc で入力を消す → もう一度 Esc で隠す。終了はトレイアイコン右クリック。
- **検索**: 上段の検索欄で見出し語・意味・タグを横断(スペース区切りで AND、大文字小文字無視、部分一致)。
  - **詳細**: 押すと「見出し語 / 意味 / タグ」ごとの検索欄が出る(全体検索とAND。タグは複数指定でAND)。
  - **辞書**: ドロップダウンで「すべて」または特定の辞書に絞る。
- **新規登録**: `＋ 新規登録`(Ctrl+N)。見出し語・タグ・意味を入力して `Ctrl+Enter` で保存。複数辞書のときは登録先も選べる。
  検索して見つからなかった語は、見出し語の初期値になります。
- **編集**: 行をダブルクリック / Enter / F2 / 詳細カードの「編集」。
- **削除**: 行を選択(Ctrl / Shift で複数)→ Delete / 「削除」。確認ダイアログあり。
- **設定**: 右上の「設定」(Ctrl+,)またはトレイメニュー。
  - ホットキーの変更(枠を選んでキーを押す)、Windows 起動時の自動起動、閉じるボタンの動作、計測ログ
  - 辞書の追加・削除・並べ替え・名前/パスの変更・参照のみの指定

| ショートカット | 動作 |
|---|---|
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 新規登録 |
| F2 / Enter | 選択行を編集 |
| Delete | 選択行を削除 |
| Ctrl+, | 設定 |
| Esc | 入力を消す → 隠す |

## 設定ファイル `fastdict.ini`
場所は exe と同じフォルダ(あればそちら。ポータブル運用)、なければ `%AppData%\fastdict\`。
初回起動時に自動作成されます。通常は「設定」ダイアログから変更できます(保存時に書き換わります)。直接編集した場合は、トレイ右クリック →「設定ファイルを再読み込み」。

```ini
[general]
hotkey = Ctrl+Alt+D      ; none で無効。修飾キー(Ctrl/Alt/Shift/Win)必須
close_to_tray = true
timing_log = false       ; true で timing.log に起動時間などを記録

[dictionary.main]        ; 先頭の辞書が既定の登録先
name = メイン
path = dictionary.db     ; 相対パスは設定ファイル基準。%APPDATA% 等も可

[dictionary.ref]
name = 参照用
path = D:\dict\ref.db
readonly = true          ; 参照のみ(登録・編集・削除不可)
```

## 起動時間の計測
- `fastdict.exe --bench [件数]` … 指定件数(既定10万)のテストDBを作り、読み込み・並べ替え・検索の時間を表示します(結果は `%AppData%\fastdict\bench.txt` にも保存)。実データには触りません。
- `timing_log = true`(または `--timing` 付きで起動)… 実際の起動で「プロセス開始 → ウィンドウ表示 → 読み込み完了 → 各検索」の時間を `timing.log`(設定ファイルと同じ場所)に記録します。
