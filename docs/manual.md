## 1. はじめに

### 起動する
`MyDictionary.exe` を起動すると、すぐに検索欄へ入力できます。インストールは要りません。

初めて起動したときに、次のファイルが `%AppData%\fastdict\` に作られます。

| ファイル | 内容 |
|---|---|
| `dictionary.db` | 辞書(「メイン」という名前で登録されます) |
| `fastdict.ini` | 設定 |
| `bookmarks.tsv` | しおり(付けたときに作られます) |

> `%AppData%` は、エクスプローラーのアドレス欄に `%AppData%\fastdict` と入力すると開けます。
> フォルダ名と設定ファイル名の `fastdict` は、開発時の名前です。これまでのデータを引き継ぐために、変えていません。

### サンプルの辞書で試す
コマンドプロンプトなどで、次を実行します。

```
MyDictionary.exe --add-sample
```

次の2つの辞書が追加されます。普段の辞書とは別のファイルなので、不要になったら設定から外すだけで済みます。

| 辞書 | 内容 |
|---|---|
| サンプル | 約300語(IT・英語・四字熟語・ことわざ・ビジネス 各60語。159語は読み付き) |
| サンプル2 | 長い文章の20語(複数の段落、箇条書き、語どうしのリンク) |

すでにサンプルの辞書がある場合は、足りない語を追加し、読みが空の語に読みを補います。自分で編集した内容は変えません。

### 終了する
ウィンドウの閉じるボタン、または Esc(検索欄が空のとき)で終了します。

常に起動したままにして、ホットキーで呼び出したい場合は、[設定](#7-設定) の「閉じるボタンや Esc で終了せず、トレイに隠して常駐する」をオンにしてください。

```

├──────────────────┬────────────────────────────────────────────┤
│ [★しおり] [並び ▼] │  見出し語                                    │
│ ──────────────── │  よみ                                        │
│ 見出し語  よみ  #タグ│  #タグ · 辞書 · 更新日時                        │
│ 意味の抜粋…   辞書 │                                             │
│ ──────────────── │  意味(本文)                                  │
│ 見出し語     #タグ │                                             │
│ 意味の抜粋…       │  参照先                                       │
│        :         │  ・リンク                                     │
│                  │                        [☆しおり] [編集] [削除] │

```

| 場所 | 内容 |
|---|---|
| 上段 | 検索欄と、辞書の選択・絞り込み・新規登録・設定のボタン |
| 左(候補リスト) | 検索に一致した語の一覧。見出し語と読み、意味の抜粋、タグを表示します。幅は固定です |
| 右(本文) | 選んだ語の内容。文字を選択してコピーできます |
| 下段 | 左に件数と操作の結果、右にキー操作の案内 |

検索に一致した部分は、候補リストでも本文でも **赤** で表示されます。

## 3. 語を引く(検索)

検索欄に文字を入力すると、その場で候補が絞り込まれます。↑ ↓ キーで候補を移動できます(検索欄にカーソルを置いたままで構いません)。

### 基本
- **見出し語・読み・意味・タグ** のどこかに含まれていれば一致します(部分一致)。
- **大文字と小文字は区別しません**。
- **スペースで区切る** と、すべてを含む語だけに絞ります(AND 検索)。例: `果物 赤`

### 読みで引く
読みを登録してある語は、読みでも引けます。**ひらがなとカタカナは区別しません**。
読みが「リンゴ」と登録されていても、「りんご」で引けます。

> ローマ字(`ringo`)では、かなの読みには一致しません。

### `#` でタグを指定する
`#` に続けて入力すると、**タグの先頭** に一致する語だけに絞ります。

| 入力 | 一致するもの |
|---|---|
| `#it` | タグが it で始まる語(IT など) |
| `#四字` | タグが「四字」で始まる語 |
| `#` | 何もしません(入力の途中とみなします) |

### `*` でワイルドカードを使う
`*` は「任意の文字列(0文字以上)」を表します。

| 入力 | 一致するもの |
|---|---|
| `app*` | app で **始まる** 見出し語(または読み) |
| `*ing` | ing で **終わる** 見出し語 |
| `a*e` | a で始まり e で終わる見出し語 |
| `#i*` | i で始まるタグ |
| `りんご*果物` | 意味の中に、りんご → 果物 の順で出てくる語 |

- 見出し語・読み・タグは **全体** に当てます。そのため `app*` は前方一致、`*ing` は後方一致になります。
- 意味は文章なので、`*` で区切った語句が **その順に出てくれば** 一致とします。
- 検索欄(全体検索)で `app*` と入力すると、意味の中に app を含む語も出ます。見出し語だけに絞りたいときは、次の「絞り込み」を使ってください。

### 絞り込み(項目ごとに検索する)
「絞り込み」ボタンを押すと、検索欄の下に3つの欄が出ます。

| 欄 | 探す場所 |
|---|---|
| 見出し語・読み | 見出し語と読みだけ |
| 意味 | 意味だけ |
| タグ | タグだけ(複数書くと、すべてを含む語に絞ります) |

検索欄と併用すると、すべての条件を満たす語だけが出ます。もう一度「絞り込み」を押すと、欄を閉じて条件を消します。

### 候補の並ぶ順番
**検索しているとき** は、一致の度合いが高い順に並びます。

1. 見出し語(または読み)が、入力と完全に一致する語
2. 見出し語(または読み)が、入力で始まる語
3. 見出し語(または読み)に、入力が含まれる語
4. 意味やタグにだけ含まれる語

**何も入力していないとき** は、選んだ並び順になります([6. しおりと並び順](#6-しおりと並び順))。

## 4. 語を登録・編集・削除する

### 登録する
「＋ 新規登録」ボタン、または **Ctrl+N** で、登録の画面が開きます。

| 欄 | 説明 |
|---|---|
| 見出し語 | 必須 |
| 読み | 任意。ひらがな・カタカナなどで書きます。読みでも検索でき、並び順にも使われます |
| タグ | 任意。スペース・カンマ・読点で区切って、いくつでも書けます。先頭の `#` は自動で外します |
| 意味 | 必須。改行できます |
| 参照先 | 任意。1行に1つ([5. 参照先](#5-参照先リンク)) |
| 登録先の辞書 | 書き込める辞書が2つ以上あるときだけ表示されます |

**Ctrl+Enter** または「保存」で登録します。Tab キーで次の欄へ移れます。

> 検索して見つからなかった語は、そのまま Ctrl+N を押すと、見出し語に入った状態で登録の画面が開きます。

### 編集する
候補リストで語を選び、次のいずれかを行います。

- **F2** または **Enter**
- 行をダブルクリック
- 本文の下の「編集」ボタン
- 右クリック →「編集…」

### 削除する
候補リストで語を選び、**Delete** キー、または「削除」ボタンを押します。確認の画面が出ます(既定は「いいえ」)。

**Ctrl+クリック** や **Shift+クリック** で複数の語を選ぶと、まとめて削除できます。確認の画面に、件数と先頭の数語が表示されます。

> 削除は元に戻せません。

### コピーする
| 場所 | 操作 |
|---|---|
| 候補リスト | **Ctrl+C** で「見出し語(タブ)意味」をコピー。右クリックで、見出し語だけ・意味だけも選べます |
| 本文 | 文字を選択して **Ctrl+C**。右クリックで「コピー」「すべて選択」も選べます |
| 入力欄 | **Ctrl+C / Ctrl+V / Ctrl+A**、右クリックのメニュー(切り取り・コピー・貼り付けなど) |

## 5. 参照先(リンク)

語には、参照先をいくつでも付けられます。本文の最後に「参照先」としてまとめて表示され、クリックすると開きます。

登録・編集の画面の「参照先」欄に、**1行に1つ** 書きます。

```
公式サイト | https://www.sqlite.org/
https://ja.wikipedia.org/wiki/SQLite
設計メモ | \\server\share\docs\notes.txt
[[トランザクション]]
```

| 書き方 | 表示 | 開く先 |
|---|---|---|
| `https://example.com/` | URL そのまま | Web ページ |
| `表示名 \| https://example.com/` | 表示名 | Web ページ |
| `表示名 \| C:\docs\memo.txt` | 表示名 | ファイルやフォルダ |
| `[[語]]` | 語 | この辞書の中の、その語 |
| `表示名 \| word:語` | 表示名 | この辞書の中の、その語 |

### 意味の文中のリンク
意味の中に書いたものも、リンクになります。

- `https://…` で始まる URL
- `[[語]]`(表示では括弧が外れ、その語へのリンクになります)

### 別の語へ移動する
`[[語]]` のリンクをクリックすると、検索欄がその語に変わり、一致する語が選ばれます。その語が登録されていなければ、その旨が表示されます(そのまま Ctrl+N で登録できます)。

### 開くときの確認
| 開く先 | 動作 |
|---|---|
| Web ページ(http / https) | そのまま開きます |
| ファイル・フォルダなど | 開く前に確認します |
| 実行ファイル(`.exe` `.bat` `.lnk` など) | 強い警告を出します(既定は「いいえ」) |

共有の辞書には、ほかの人が登録したリンクも入ります。実行ファイルへのリンクは、登録した人と内容を信頼できる場合だけ開いてください。

**Ctrl+O** で、選んでいる語の最初の参照先を開けます。

## 6. しおりと並び順

### しおり
あとで見返したい語に、しおりを付けられます。

- 語を選んで、本文の下の「☆ しおり」ボタン、または **Ctrl+D** で付け外しします。
- しおりを付けた語は、候補リストに **★** が付きます。
- 候補リストの上の「★ しおり」ボタンを押すと、**しおりを付けた語だけ** を、**付けた順** に表示します。
- その状態で検索欄に入力すると、しおりの中を検索できます。
- もう一度「★ しおり」を押すと、元の表示に戻ります。

しおりは辞書のファイルではなく、自分の設定フォルダに保存されます。共有の辞書を使っていても、しおりは人ごとに別々です。

### 並び順
候補リストの上の「並び」ボタンで、何も検索していないときの並び順を選べます。選んだ並び順は、次に起動したときも使われます。

| 並び順 | 内容 |
|---|---|
| 見出し語順 | 下の表の順 |
| 更新が古い順 | 更新日時の古いものが上 |
| 更新が新しい順 | 更新日時の新しいものが上 |
| しおり追加順 | しおりの表示中だけ選べます |

**見出し語順** は、次の順に並びます。

| 順 | 対象 | 並べ方 |
|---|---|---|
| 1 | 数字で始まる語 | 見出し語の順 |
| 2 | 英字で始まる語 | アルファベット順(大文字小文字は区別しない)。読みを付けていても、見出し語の綴りで並べます |
| 3 | 日本語の語 | 五十音順。読みがあれば読み、無ければ見出し語そのもので並べます。ひらがなとカタカナは同じ扱いです |
| 4 | 読みの無い漢字の語 | 文字コードの順(五十音にはなりません) |

> 漢字の語を五十音順に並べたいときは、読みを付けてください。

## 7. 設定

「設定」ボタン、または **Ctrl+,** で開きます。「保存」を押すと反映されます。

### 全般
| 項目 | 説明 |
|---|---|
| 呼び出しホットキー | ほかのアプリを使っているときでも、このキーで辞書を呼び出せます(既定は Ctrl+Alt+D)。枠を選んでキーを押すと変更できます。BackSpace で無効にできます |
| 閉じるボタンや Esc で終了せず、トレイに隠して常駐する | オンにすると、閉じても終了せず、タスクバー右下のトレイに残ります。終了は、トレイのアイコンを右クリック →「終了」 |

> ホットキーは、アプリが起動している間だけ使えます。ホットキーで呼び出したい場合は、トレイに常駐する設定をオンにしてください。

### Windows の起動と同時に常駐させる
1. 設定で「トレイに隠して常駐する」をオンにします。
2. `Win + R` を押し、`shell:startup` と入力してフォルダを開きます。
3. `MyDictionary.exe` のショートカットを、そのフォルダに作ります。
4. ショートカットのプロパティを開き、「リンク先」の末尾に ` --background` を付け足します。

### 辞書
辞書の追加・削除・並べ替え、名前とパスの変更、参照のみの指定、取り込み・書き出しができます。くわしくは次の章を参照してください。

設定の画面の左下に、アプリの版(例: MyDictionary 2.00)が表示されます。

### 設定ファイルを直接編集する
設定は `fastdict.ini` に保存されています。トレイのアイコンを右クリック →「設定ファイルを開く」で編集できます。編集後は「設定ファイルを再読み込み」を選んでください。

```ini
[general]
hotkey = Ctrl+Alt+D      ; none で無効。Win キーを使う場合はここで指定(例: Win+Shift+D)
close_to_tray = false    ; true にすると、閉じてもトレイに常駐
sort = word              ; word / updated_asc / updated_desc

[dictionary.d1]          ; 先頭の辞書が、既定の登録先
name = メイン
path = dictionary.db     ; 相対パスは、この設定ファイルのあるフォルダが基準

[dictionary.d2]
name = 共有
path = \\server\share\dict\team.db
readonly = true          ; 参照のみ
```

### 持ち運んで使う(ポータブル)
`MyDictionary.exe` と同じフォルダに `fastdict.ini` があれば、そちらが使われます。辞書のパスを相対パスにしておけば、フォルダごと USB メモリなどで持ち運べます。

## 8. 複数の辞書を使う

### 辞書を追加する
設定の「辞書」で「追加…」を押し、ファイルを選びます。新しいファイル名を入力すると、新しい辞書が作られます。

| ボタン | 動作 |
|---|---|
| 追加… | 辞書を追加します |
| 削除 | 一覧から外します(**ファイルは削除されません**) |
| ↑ 上へ / ↓ 下へ | 順番を変えます。先頭の辞書が、既定の登録先になります |
| 参照… | 辞書のファイルの場所を変えます |
| 参照のみ | オンにすると、その辞書では登録・編集・削除ができなくなります |

### 検索する辞書を選ぶ
上段の「辞書」ボタンを押すと、辞書の一覧が出ます。検索に含める辞書にチェックを入れて「OK」を押します。

- 一部の辞書だけを選んでいる間は、ボタンが「辞書: 2 / 3」のように表示されます。
- 辞書が2つ以上あるときは、候補リストと本文に辞書の名前が表示されます。
- この選択は、起動するたびに「すべて」に戻ります。

## 9. 取り込みと書き出し

設定の「辞書」で辞書を選び、「取り込む…」「書き出す…」を押します。

### 書き出す(JSON)
選んだ辞書のすべての語を、JSON ファイルに書き出します。見出し語、読み、意味(改行もそのまま)、タグ、参照先、更新日時が入ります。
書き出したファイルは、「取り込む…」でそのまま取り込めます。バックアップや、別の辞書への移し替えに使えます。

> しおりは書き出しに含まれません。

### 取り込む(JSON / CSV / TSV)
ファイルの種類は、自動で見分けます。取り込む前に、件数と先頭の数語が確認の画面に表示されます。

- **見出し語と意味が両方同じ語は、重複として飛ばします**。同じファイルを取り込み直しても増えません。
- 途中で失敗した場合、辞書は変更されません。

#### JSON
「書き出す…」で作られる形式です。自分で書く場合は、`word` と `meaning` があれば取り込めます。

```json
[
  { "word": "一期一会", "reading": "いちごいちえ", "meaning": "一生に一度の出会い。", "tags": ["四字熟語"] },
  { "word": "apple", "meaning": "りんご。\n赤い果物。" }
]
```

#### CSV / TSV
Excel で作った表を、そのまま取り込めます。

- **1行目に列名を書く**と、列名で対応づけます(順番は自由)。

  | 列名 | 別の書き方 |
  |---|---|
  | 見出し語 | 単語、語、word |
  | 意味 | 説明、meaning |
  | 読み | よみ、ふりがな、reading |
  | タグ | tag、tags |
  | 参照先 | リンク、link、url |

- 列名の行が無いときは、左から **見出し語、意味、タグ、参照先、読み** の順とみなします。見出し語と意味以外は省略できます。
- 文字コードは、UTF-8・UTF-16・Shift_JIS(日本語版 Excel の「CSV」)を自動で見分けます。
- セルの中の改行や、カンマを含む値も、Excel の出力のままで取り込めます。TSV で改行を入れたいときは `\n` と書きます。

`sample/sample.tsv` と `sample/sample2.tsv` が、取り込める TSV の見本です。

## 10. 共有フォルダで複数人が使う

辞書のファイルを共有フォルダに置けば、複数の人で同じ辞書を使えます。

> **大切なこと**: 辞書の保存に使っている SQLite は、共有フォルダ上での同時書き込みを完全には保証できません。まれにファイルが壊れる可能性があります。このアプリは、壊れにくく、壊れても戻せるように工夫していますが、**壊れないことを保証するものではありません**。大事な辞書は、定期的に書き出して、別の場所にも保存してください。

### このアプリが行っていること
書き込み(登録・編集・削除・取り込み)のたびに、次の手順を踏みます。

1. ほかの人が書き込み中なら、最大5秒待ちます。
2. 書き込む前に、ファイルが壊れていないか検査します。壊れていたら書き込みません。
3. 直前の状態を、**自分の PC** に保存します。
4. 書き込みます。
5. もう一度検査し、壊れていたら、3 で保存した状態に **自動で戻します**。
6. 検査に通った最新の状態も、自分の PC に保存します。

このほか、次の動作をします。

- **ほかの人の変更を取り込む**: ウィンドウを前面に出したとき、ファイルが変わっていれば自動で読み直します。
- **編集の衝突を知らせる**: 自分が開いた後に、ほかの人が同じ語を変更・削除していた場合は、上書きせずに知らせます。
- **壊れていたら復元を案内する**: 起動時や書き込み時にファイルが壊れていた場合、自分の PC のバックアップから復元するか確認します。

### バックアップの場所
`%LocalAppData%\fastdict\backup\<辞書名>-<記号>\`

| ファイル | 内容 |
|---|---|
| `latest.db` | 最後に書き込んだ直後の状態 |
| `pre-write.db` | 最後に書き込む直前の状態 |
| `gen-<数字>.db` | 10分ごとの世代バックアップ(10世代まで) |

### 使う人が気をつけること
- 全員が、同じ版のアプリを使ってください。
- 大量の取り込みは、ほかの人が使っていない時間に行ってください。
- 「壊れている」と表示されたら、ほかの人にも知らせ、いったん全員が閉じてから復元してください。
- 参照するだけの人は、設定で「参照のみ」にしておくと安全です。

### 知っておいてほしい限界
- バックアップは、**その PC から書き込んだとき** に作られます。参照しかしていない PC には、復元に使えるバックアップがありません。
- 復元すると、その時点より後の変更(ほかの人の分を含む)は失われます。
- 書き込みのたびに検査とバックアップを行うため、大きな辞書を遅い回線で使うと、保存に時間がかかります(検索の速さには影響しません)。

## 11. キー操作の一覧

| キー | 動作 |
|---|---|
| ↑ ↓ / PageUp / PageDown | 候補を移動(検索欄にいるままで使えます) |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 新規登録 |
| F2 / Enter(候補リストで) | 編集 |
| Delete(候補リストで) | 削除 |
| Ctrl+D | しおりを付ける / 外す |
| Ctrl+O | 最初の参照先を開く |
| Ctrl+C | コピー(候補リスト: 見出し語と意味 / 本文・入力欄: 選択した文字) |
| Ctrl+V / Ctrl+A | 貼り付け / すべて選択(入力欄。Ctrl+A は本文でも使えます) |
| Ctrl+, | 設定 |
| Ctrl+Enter | 登録・編集の画面で保存 |
| Esc | 入力があれば消す。無ければ閉じる |
| ホットキー(既定 Ctrl+Alt+D) | ほかのアプリから呼び出す(起動中のみ) |

### 起動時の指定
| 指定 | 動作 |
|---|---|
| `--background` | ウィンドウを出さずに起動します(トレイに常駐する設定のときに使います) |
| `--add-sample` | サンプルの辞書を追加・更新します |
| `--bench [件数]` | 指定した件数のテスト用データで、読み込みと検索の時間を計ります(実際の辞書には触りません) |

## 12. 困ったとき

### 起動できないとき
**「Windows によって PC が保護されました」と出る**
実行ファイルに署名が無いために出る警告です。「詳細情報」を押し、「実行」を選ぶと起動できます。

**「アプリケーション制御ポリシーによってこのファイルがブロックされました」と出る**
Windows 11 の Smart App Control が、署名のない実行ファイルを止めています。「Windows セキュリティ」→「アプリとブラウザー コントロール」→「Smart App Control」で状態を確認できます。
オフにすれば起動できますが、**一度オフにすると、Windows を再インストールしない限りオンに戻せません**。会社や学校の PC では、管理者に相談してください。

### ホットキーが効かない
- アプリが起動していますか。既定では、閉じると終了します。常駐させるには、設定の「トレイに隠して常駐する」をオンにしてください。
- ほかのアプリが同じキーを使っていると、登録できません(その場合、下段に表示が出ます)。設定で別のキーに変えてください。

### 閉じても終了しない / 終了してしまう
設定の「閉じるボタンや Esc で終了せず、トレイに隠して常駐する」で切り替えられます。常駐中の終了は、トレイのアイコンを右クリック →「終了」です。

### 語が一覧に出ない
- 検索欄や「絞り込み」の欄に、文字が残っていませんか。Esc で消せます。
- 「辞書」ボタンが「辞書: 1 / 3」のようになっていませんか。検索する辞書を絞っています。
- 「★ しおり」が押された状態になっていませんか。しおりを付けた語だけを表示しています。

### 漢字の語が、五十音順に並ばない
読みが登録されていない漢字の語は、位置を決められないため、最後にまとまります。読みを付けてください。

### 取り込んだら文字化けした
ファイルを、メモ帳などで「UTF-8」を選んで保存し直してから、もう一度取り込んでください。

### 「辞書ファイルが壊れています」と出た
画面の案内に従って、バックアップから復元できます。共有の辞書の場合は、ほかの人に知らせ、全員が閉じてから実行してください。
復元に使えるバックアップが無い場合は、最後に書き出した JSON ファイルから、新しい辞書に取り込み直してください。

### 「他の人が先にこの項目を変更または削除しました」と出た
自分が開いた後に、ほかの人が同じ語を変更しています。上書きはされていません。読み直された内容を確認して、必要ならもう一度編集してください。

### 設定をやり直したい
アプリを終了してから、`%AppData%\fastdict\fastdict.ini` を削除してください。次に起動したとき、初期の設定で作り直されます(辞書のファイルは消えません)。
