# fastdict

Rust + windows-rs(Win32 標準コントロール)+ SQLite(静的リンク)の個人用辞書。
起動が速く、入力中に絞り込めることを重視しています。

## 使い方
電子辞書と同じく「入力 → 候補 → 本文」の流れです。起動(または呼び出し)直後から検索欄に入力できます。

- **上段**: 検索欄 / 辞書(検索に含める辞書をチェックで選ぶ)/ 絞り込み / ＋ 新規登録 / 設定
- **左**: 候補リスト(見出し語と意味の抜粋。検索語は赤で強調)。上部に「★ しおり」(しおりだけ表示)と「並び」(並び順)
- **右**: 本文(見出し語、タグ・辞書・更新日時、意味、末尾に参照先。検索語は赤で強調。文字を選択してコピー可)

| 操作 | 動作 |
|---|---|
| 文字を入力 | 見出し語・読み・意味・タグを横断して絞り込み(スペース区切りで AND、大文字小文字無視、部分一致) |
| 読みを入力 | 読みを登録した語は、読みでも引ける(ひらがな・カタカナは区別しない。「りんご」で読み「リンゴ」に一致) |
| ↑ ↓ / PageUp / PageDown | 検索欄にいるまま候補を移動 |
| `#タグ` と入力 | タグの先頭に一致するものだけに絞る(例: `#it`)。`#` だけなら何もしない |
| `*` を使う | ワイルドカード。`app*` = app で始まる見出し語、`*ing` = ing で終わる、`a*e` = a で始まり e で終わる。タグも同じ(`#i*`)。意味は「`りんご*果物`」のように、語句がその順に出てくるものに一致 |
| 絞り込み | 「見出し語 / 意味 / タグ」ごとの検索欄を表示(全体検索と AND。タグは複数指定で AND) |
| 辞書 | 検索に含める辞書をチェックで選ぶ(複数可)。絞っている間はボタンに「辞書: 2 / 3」と表示 |
| Ctrl+N | 新規登録(検索して見つからなかった語は、見出し語の初期値になる) |
| F2 / Enter / ダブルクリック | 選択した語を編集 |
| Delete | 選択した語を削除(Ctrl / Shift で複数選択可。確認あり) |
| Ctrl+O | 選択した語の参照先を開く(複数あれば先頭) |
| Ctrl+D | 選択した語にしおりを付ける / 外す |
| Alt+← | リンクで別の語へ移動する前に戻る |
| Ctrl+C | 候補リスト: 選択した語の「見出し語<TAB>意味」をコピー / 本文・入力欄: 選択した文字をコピー |
| Ctrl+V / Ctrl+A | 入力欄で貼り付け / 全選択(本文欄でも Ctrl+A 可) |
| 右クリック | 候補リスト: コピー・しおり・編集・削除 / 本文: コピー・すべて選択・リンクを開く / 入力欄: 切り取り・コピー・貼り付けなど |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+, | 設定 |
| Esc | 入力を消す → もう一度で隠す |
| ホットキー(既定 Ctrl+Alt+D) | どこからでも呼び出し |

終了はトレイアイコンの右クリックから。Windows 起動時に常駐させたい場合は、スタートアップフォルダ(`shell:startup`)に
`fastdict.exe --background` のショートカットを置いてください。

## 読み
登録・編集ダイアログの「読み」欄に、ひらがな・カタカナなどで書きます(任意)。

- 検索: 全体検索と、絞り込みの「見出し語・読み」欄の対象になります。ひらがなとカタカナは区別しません。ワイルドカードも使えます。
- 表示: 候補リストでは見出し語の右、本文では見出し語の下に出ます。
- 並び: 「見出し語順」は、読みがあれば読み、無ければ見出し語そのものを使って、次の順に並べます。
  1. 数字で始まるもの(例: 5W1H)
  2. 英字で始まるもの(読みの無い英単語。大文字小文字は区別しない)
  3. かなで始まるもの(五十音順)。読みを付けた語は英単語でも漢字でもここに入り、読みの無いひらがな・カタカナの語も同じ並びに入る
  4. 読みの無い漢字の語(文字コード順。五十音にはならないので、読みを付けるのがおすすめ)

## 並び順としおり
- **並び**: 見出し語順(検索中は一致度の高い順)/ 更新が古い順 / 更新が新しい順。選んだ並び順は次回も使われます。
- **しおり**: 語を選んで「☆ しおり」(Ctrl+D)で付け外し。候補リストでは ★ が付きます。
  - 「★ しおり」を押すと、しおりを付けた語だけを **追加した順** に表示します。その状態で検索欄に入力すると、しおりの中を検索できます。
  - しおりは辞書ファイルではなく、各自の設定フォルダ(`bookmarks.tsv`)に保存します。共有の辞書でも人ごとに別々で、参照のみの辞書の語にも付けられます。

## 参照先(リンク)
意味はプレーンテキストのままで、参照先は Wikipedia の脚注のように **本文の最後にまとめて表示** します。

登録・編集ダイアログの「参照先」欄に、1行に1つ書きます(複数可)。

```
公式サイト | https://www.sqlite.org/
https://ja.wikipedia.org/wiki/SQLite
設計メモ | \\\\server\\share\\docs\\notes.txt
```

- `表示名 | 開く先` と書くと表示名付き、開く先だけ書けばそのまま表示されます(`[表示名](開く先)` の形でも可)。
- 開く先は URL のほか、ファイルやフォルダのパスも指定できます。
- **別の語へのリンク**: `[[語]]` と書くと、この辞書の中のその語へ移動します(`類義語 | word:語` で表示名付き)。
  意味の文中に `[[語]]` と書いても同じです(表示では括弧が外れます)。移動後は Alt+← で戻れます。
- 本文のリンクをクリックするか、Ctrl+O(先頭の参照先)で開きます。意味の文中に書いた URL も自動でリンクになります。
- Web ページ(http / https)はそのまま開きます。ファイルやフォルダは、開く前に確認します。
- `.exe` `.bat` `.lnk` など実行される可能性のあるファイルは、強い警告を出します(既定は「いいえ」)。
  共有の辞書には他の人が登録したリンクも入るためです。

古い版で作った辞書は、最初の書き込みのときに参照先の列が自動で追加されます(既存のデータはそのまま)。

## エクスポート / インポート
設定 → 辞書を選ぶ →「書き出す…」「取り込む…」。

### JSON(書き出し・取り込み)
意味に改行が入っていても崩れない JSON で書き出します。書き出したファイルは、そのまま取り込めます(バックアップや、別の辞書への移し替えに使えます)。

```json
{
  "format": "fastdict",
  "version": 1,
  "entries": [
    {
      "word": "一期一会",
      "reading": "いちごいちえ",
      "meaning": "一生に一度の出会い。\nその機会を大切にすべきだという教え。",
      "tags": ["四字熟語"],
      "links": ["公式サイト | https://example.com/", "[[温故知新]]"],
      "updated_at": 1730000000,
      "updated": "2024/10/27 12:33:20"
    }
  ]
}
```

- 取り込みに必須なのは `word` と `meaning` だけです。`entries` を省いて、配列をそのまま書いてもかまいません。
- `tags` は配列でも、区切り文字入りの文字列でも可。`links` の代わりに `link`(文字列)でも可。
- `updated_at`(UNIX 秒)があれば、更新日時として引き継ぎます。`updated` は人が読むための日本時間で、取り込みには使いません。

### CSV / TSV(取り込み)
- 1行目に列名を書くと、列名で対応づけます(順不同): `見出し語` `読み` `意味` `タグ` `参照先`(`word` `reading` `meaning` `tags` `link` / `url` でも可)
- 列名の行が無ければ、左から **見出し語, 意味, タグ, 参照先, 読み** の順とみなします(見出し語と意味以外は省略可)
- 文字コード: UTF-8(BOM 有無どちらも)、UTF-16、Shift_JIS(日本語版 Excel の「CSV」)を自動判別
- 区切り: 拡張子が `.csv` ならカンマ、`.tsv` ならタブ。それ以外は内容から判別
- 値は `"..."` で囲めます(カンマ・改行を含む値。Excel の出力そのまま)。TSV で改行を入れたいときは `\n` と書けます
- タグはスペース・カンマ・読点区切り。先頭の `#` は外します

### 共通
- 見出し語と意味の両方が同じ語は重複として飛ばすので、同じファイルを取り込み直しても増えません
- 取り込みは1トランザクションで行い、失敗したら何も変わりません(書き込み前のバックアップも作られます)
- しおりは各自の設定に保存しているため、書き出しには含まれません

サンプルデータ `sample/sample.tsv` も、取り込める TSV です。

## サンプルデータ
```
fastdict.exe --add-sample
```
約300語(IT・英語・四字熟語・ことわざ・ビジネス 各60語。四字熟語・ことわざなど159語は読み付き)の「サンプル」辞書を、設定ファイルと同じフォルダに `sample.db` として作り、
設定に追加します。普段の辞書とは別ファイルです。不要になったら、設定の「辞書」から外してください。

## 設定
右上の「設定」(Ctrl+,)またはトレイメニューから。

- ホットキーの変更(枠を選んでキーを押す)、閉じるボタンの動作
- 辞書の追加・削除・並べ替え・名前/パスの変更・参照のみの指定

設定は `fastdict.ini` に保存されます。場所は exe と同じフォルダ(あればそちら。ポータブル運用)、なければ `%AppData%\fastdict\`。
直接編集した場合は、トレイ右クリック →「設定ファイルを再読み込み」。

```ini
[general]
hotkey = Ctrl+Alt+D      ; none で無効。修飾キー(Ctrl/Alt/Shift/Win)必須
close_to_tray = true

[dictionary.d1]          ; 先頭の辞書が既定の登録先
name = メイン
path = dictionary.db     ; 相対パスは設定ファイル基準。%APPDATA% 等も可

[dictionary.d2]
name = 共有
path = \\server\share\dict\team.db
readonly = true          ; 参照のみ(登録・編集・削除不可)
```

## 共有フォルダで複数人が使う場合
SQLite はネットワーク共有上のロックを完全には信頼できないため、破損を「防ぎきる」ことはできません。
そのうえで、壊れにくく・壊れても戻せるように、書き込みのたびに次の手順を踏みます。

1. 書き込みロックを取得(他の人が書き込み中なら最大5秒待つ)
2. 書き込み前に整合性を検査(すでに壊れていたら書き込まず、復元を案内)
3. 直前の状態を **このPCのローカル** にスナップショット(`pre-write.db`)。10分に1回は世代バックアップも残す(10世代)
4. 1トランザクションで書き込み
5. ファイルを開き直して整合性を検査。壊れていたらスナップショットから **自動でロールバック**
6. 検査に通った最新の状態もローカルへ保存(`latest.db`)

バックアップの場所: `%LocalAppData%\fastdict\backup\<辞書名>-<パスのハッシュ>\`

そのほか:
- **他の人の変更の取り込み**: ウィンドウを前面に出したとき、ファイルが変わっていれば自動で読み直します。
- **編集の衝突**: 自分が開いた後に他の人が同じ語を変更/削除していた場合、上書きせずに知らせて読み直します。
- **起動時に壊れていた場合**: このPCのバックアップから復元するか確認します(復元すると、その時点より後の他の人の変更は失われます)。

限界: バックアップは「このPCから書き込んだとき」に作られます。参照しかしていないPCには復元元がありません。
また、復元の瞬間に他の人が書き込んでいる場合の競合までは防げません。重要な辞書は、共有フォルダ側の定期バックアップも併用してください。

## 計測
`fastdict.exe --bench [件数]` … 指定件数(既定10万)のテストDBを作り、読み込み・並べ替え・検索の時間を表示します(実データには触りません)。
