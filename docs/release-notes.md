すぐ開いて、すぐ引ける、個人・小さなチーム向けの辞書アプリです(Windows 10 / 11、64ビット)。

## 使いはじめる
1. 下の **MyDictionary.exe** をダウンロードして、好きな場所に置きます(インストールは要りません)。
2. 起動すると、すぐに検索欄へ入力できます。
3. サンプルの辞書を試すには、リポジトリの [sample フォルダ](https://github.com/ParticlePudding/MyDictionary/tree/master/sample) の TSV をダウンロードし、「設定」→「取り込む…」で取り込みます。

使い方は [取扱説明書](https://github.com/ParticlePudding/MyDictionary/blob/master/docs/manual.md) を参照してください。

## 次の版の内容(未リリース。配布するときに版を上げ、この見出しを直す)
- 検索: OR(`|` / `OR`)と除外(`-`)、`#タグ`、ワイルドカード(`*`)、項目ごとの絞り込み、一致の度合いの順の並び。全角・半角、大文字・小文字、ひらがな・カタカナ、半角カナを区別しない。読みの欄
- 登録: 同じ見出し語の知らせ、入力中に閉じるときの確認、画面の大きさの変更、タグを一覧から選ぶ
- 取り込みと書き出し: CSV / TSV / JSON。書き出した表を直して上書きで取り込む(管理用の番号で照合)。上書きの詳細と、Excel で崩れた値の検出
- 直前の操作を元に戻す(登録・編集・削除・取り込み・タグの変更)
- タグの一覧(名前の変更・統合・削除)、しおり一覧、F5 での読み直し、F1 で説明書
- リンク: `[[語]]` で語どうしをつなぐ、未登録の語へのリンク、Alt+← で戻る、行き先の確認と、実行ファイル・偽装したリンクへの強い警告
- 意味の中に画像を表示(`![説明](パス)`、「画像を追加…」)
- 暗い配色(明るい / 暗い / Windows の設定に合わせる)
- 設定ファイル: 行末のコメント、保存しても書かれていたパスの形を保つ、.bak の控え、ほかの人の変更の確認
- 配布物に説明書(`manual.md`)を入れた

## 2.00 の内容
旧版(.NET / WinForms)から、Rust + Win32 で作り直しました。

- 起動してすぐ引ける(検索はメモリ上で行い、入力のたびに絞り込み)
- 検索: 部分一致、スペース区切りの AND、`#タグ`、`*` のワイルドカード、読み(ひらがな・カタカナを区別しない)
- 一致した語の強調表示、参照先のリンク、別の語へのリンク(`[[語]]`)
- しおり、並び順(見出し語順 / 更新日時)
- 複数の辞書、参照のみの辞書
- JSON の書き出し・取り込み、CSV / TSV の取り込み
- 共有フォルダ向けの安全な書き込み(書き込み前後のバックアップと検査、破損時の復元)
- 設定ファイルごと共有フォルダに置いて配る運用(共用フォルダで運用する設定、ウィンドウに表示する名前)

## 注意
- 実行ファイルには署名がありません。初回の起動時に、Windows の警告(「Windows によって PC が保護されました」)が出ることがあります。「詳細情報」→「実行」で起動できます。
- Windows 11 の Smart App Control が有効な PC では、起動がブロックされることがあります(くわしくは取扱説明書の「困ったとき」)。
- データは `%AppData%\MyDictionary\` に保存されます。
