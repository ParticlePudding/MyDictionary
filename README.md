# MyDictionary

すぐ開いて、すぐ引ける、個人・小さなチーム向けの辞書アプリです(Windows 用)。
自分で登録した語を、見出し語・読み・意味・タグから、入力したそばから絞り込めます。

- **速い**: 起動してすぐ入力できます。10万語でも、検索は1回あたり数十ミリ秒以内です(計測値は [仕様書](docs/spec.md#性能) を参照)。
- **小さい**: 実行ファイル1つ(約1.6MB)。インストールやランタイムは要りません。
- **引きやすい**: 部分一致、スペース区切りの AND、`A|B` の OR、`-A` の除外、`#タグ`、`*` のワイルドカード、読み。全角・半角、ひらがな・カタカナ、大文字・小文字は区別しません。
- **整えやすい**: タグの一覧から絞り込み。書き方のばらついたタグ(「IT」と「it」)を、まとめて1つにそろえられます。
- **読みやすい**: 左に候補、右に本文。一致した語は赤で強調。意味の中のリンクや、別の語へのリンク(`[[語]]`)をたどれます。画像も表示できます(`![説明](パス)`)。
- **共有できる**: 複数の辞書を切り替えて使えます。共有フォルダの辞書は、書き込みのたびにバックアップと検査を行い、壊れたら直前の状態に戻します。
- **持ち出せる**: JSON・CSV・TSV で書き出し・取り込み。CSV を Excel で直して、上書きで取り込めます。
- **やり直せる**: 登録・編集・削除・取り込みは、直後なら「元に戻す」で取り消せます。

## はじめかた

### ダウンロードして使う
[Releases](https://github.com/ParticlePudding/MyDictionary/releases) から `MyDictionary.exe` をダウンロードし、好きな場所に置いて起動します。インストールは要りません。

### 自分でビルドする
Rust(MSVC 版)を入れた Windows で、次を実行します。

```
cargo build --release
```

`target\release\MyDictionary.exe` ができます。

### サンプルの辞書を試す
`sample` フォルダに、取り込める見本のデータがあります。

| ファイル | 内容 |
|---|---|
| `sample/sample.tsv` | 約300語(IT・英語・四字熟語・ことわざ・ビジネス) |
| `sample/sample2.tsv` | 長い文章の20語(複数の段落、箇条書き、語どうしのリンク) |

1. アプリの「設定」を開き、「辞書」の一覧で取り込み先の辞書を選びます。
   普段の辞書と分けたい場合は、先に「追加…」でサンプル用の辞書を作ってください。
2. 「取り込む…」を押し、上のファイルを選びます。

> **起動がブロックされるとき**: 実行ファイルには署名がありません。Windows の警告が出た場合は「詳細情報」→「実行」で起動できます。
> Windows 11 の Smart App Control が有効な PC では、起動やビルドがブロックされることがあります。
> くわしくは [取扱説明書](docs/manual.md#起動できないとき) を参照してください。

## 構成

```
src/       プログラム(Rust)
assets/    アイコン
sample/    サンプルデータ(TSV。取り込みの見本にもなります)
docs/      取扱説明書・仕様書など
```

データは、既定では `%AppData%\MyDictionary\` に保存されます(辞書 `dictionary.db`、設定 `MyDictionary.ini`、しおり `bookmarks.tsv`)。
