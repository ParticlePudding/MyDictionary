## 1. はじめに

### 起動する
`MyDictionary.exe` を起動すると、すぐに検索欄へ入力できます。インストールは要りません。

初めて起動したときに、次のファイルが `%AppData%\MyDictionary\` に作られます。

| ファイル | 内容 |
|---|---|
| `dictionary.db` | 辞書(「メイン」という名前で登録されます) |
| `MyDictionary.ini` | 設定 |
| `bookmarks.tsv` | しおり(付けたときに作られます) |

> `%AppData%` は、エクスプローラーのアドレス欄に `%AppData%\MyDictionary` と入力すると開けます。

### サンプルの辞書で試す
配布物の `sample` フォルダに、取り込める見本のデータがあります。

| ファイル | 内容 |
|---|---|
| `sample.tsv` | 約300語(IT・英語・四字熟語・ことわざ・ビジネス 各60語。159語は読み付き) |
| `sample2.tsv` | 長い文章の20語(複数の段落、箇条書き、語どうしのリンク) |

1. 「設定」を開き、「辞書」の一覧で取り込み先の辞書を選びます。
   普段の辞書と分けたい場合は、先に「追加…」でサンプル用の辞書を作ってください(不要になったら、一覧から外すだけで済みます)。
2. 「取り込む…」を押し、ファイルを選びます。

同じファイルをもう一度取り込んでも、語は増えません。くわしくは [9. 取り込みと書き出し](#9-取り込みと書き出し) を参照してください。

### 終了する
ウィンドウの閉じるボタン、または Esc(検索欄が空のとき)で終了します。

常に起動したままにして、ホットキーで呼び出したい場合は、[設定](#7-設定) の「閉じるボタンや Esc で終了せず、トレイに隠して常駐する」をオンにしてください。

## 2. 画面の見かた

```
┌───────────────────────────────────────────────────────────────┐
│ [ 検索欄                      ] [辞書] [絞り込み] [＋新規登録] [設定] │
├──────────────────┬────────────────────────────────────────────┤
│ [★しおり] [並び ▼] │  見出し語                                    │
│ ──────────────── │  よみ                                        │
│ 見出し語  よみ  #タグ│  #タグ · 辞書 · 更新日時                        │
│ 意味の抜粋…   辞書 │                                             │
│ ──────────────── │  意味(本文)                                  │
│ 見出し語     #タグ │                                             │
│ 意味の抜粋…       │  参照先                                       │
│        :         │  ・リンク                                     │
│                  │                        [☆しおり] [編集] [削除] │
├──────────────────┴────────────────────────────────────────────┤
│ 件数・操作の結果                          キー操作の案内         │
└───────────────────────────────────────────────────────────────┘
```

| 場所 | 内容 |
|---|---|
| 上段 | 検索欄と、辞書の選択・絞り込み・新規登録・設定のボタン |
| 左(候補リスト) | 検索に一致した語の一覧。見出し語と読み、意味の抜粋、タグを表示します。幅は固定です |
| 右(本文) | 選んだ語の内容。文字を選択してコピーできます |
| 下段 | 左に件数と操作の結果、右にキー操作の案内 |

検索に一致した部分は、候補リストでも本文でも **赤** で表示されます。

## 3. 語を引く(検索)

検索欄に文字を入力すると、その場で候補が絞り込まれます。↑ ↓ キーで候補を移動できます(検索欄にカーソルを置いたままで構いません)。

### 基本
- **見出し語・読み・意味・タグ** のどこかに含まれていれば一致します(部分一致)。
- **スペースで区切る** と、すべてを含む語だけに絞ります(AND 検索)。例: `果物 赤`

### 区別しない文字
次の違いは、区別せずに探します。どちらの書き方で登録してあっても、どちらの書き方でも引けます。

| 区別しないもの | 例 |
|---|---|
| 大文字と小文字 | `API` と `api` |
| 全角と半角(英数字・記号・スペース) | `ＡＰＩ` と `API` |
| 半角カタカナと全角カタカナ | `ｻｰﾊﾞ` と `サーバ` |
| ひらがなとカタカナ | `りんご` と `リンゴ` |

- 見出し語・読み・意味・タグのすべてが対象です。
- 検索の記号(`#` `*` `|` `-`)も、全角で入力して構いません。
- 長音や小さい字の違い(「サーバ」と「サーバー」)は、別の語として扱います。濁点の有無(「か」と「が」)も区別します。

### 読みで引く
読みを登録してある語は、読みでも引けます。
読みが「リンゴ」と登録されていても、「りんご」で引けます。

> ローマ字(`ringo`)では、かなの読みには一致しません。

### `#` でタグを指定する
`#` に続けて入力すると、**タグの先頭** に一致する語だけに絞ります。

| 入力 | 一致するもの |
|---|---|
| `#it` | タグが it で始まる語(IT など) |
| `#四字` | タグが「四字」で始まる語 |
| `#"IT"` | タグが IT **そのもの** の語(`#IT` だと、ITIL のような IT で始まるタグの語も出ます) |
| `#` | 何もしません(入力の途中とみなします) |

本文に表示されているタグをクリックすると、そのタグの語だけを表示します(検索欄に `#"タグ"` が入ります)。Alt+← で、前の表示に戻れます。

### `*` でワイルドカードを使う
`*` は「任意の文字列(0文字以上)」を表します。

| 入力 | 一致するもの |
|---|---|
| `app*` | app で **始まる** 見出し語(または読み) |
| `*ing` | ing で **終わる** 見出し語 |
| `a*e` | a で始まり e で終わる見出し語 |
| `#i*` | i で始まるタグ |
| `りんご*果物` | 意味の中に、りんご → 果物 の順で出てくる語 |

- 見出し語・読み・タグは **全体** に当てます。そのため `app*` は前方一致、`*ing` は後方一致になります。
- 意味は文章なので、`*` で区切った語句が **その順に出てくれば** 一致とします。
- 検索欄(全体検索)で `app*` と入力すると、意味の中に app を含む語も出ます。見出し語だけに絞りたいときは、次の「絞り込み」を使ってください。

### どちらかを含む(OR)、含まない(除外)

| 入力 | 一致するもの |
|---|---|
| `りんご|バナナ` | りんご か バナナ の **どちらか** を含む語 |
| `りんご OR バナナ` | 上と同じ(`OR` は大文字で書きます。小文字の `or` は普通の検索語です) |
| `果物 -赤い` | 果物 を含み、赤い を **含まない** 語 |
| `りんご|バナナ -赤い` | (りんご か バナナ)を含み、赤い を含まない語 |
| `-#IT` | タグが IT で始まらない語 |

- `|` の前後にスペースを入れても構いません(`りんご | バナナ`)。
- `-` は、語の **先頭** に付けたときだけ「含まない」の意味になります。`e-mail` や `Wi-Fi` のように途中にある `-` は、ただの文字です。
- `-fno-rtti` のように `-` で始まる語を引きたいときは、先頭の `-` を外して `fno-rtti` と入力してください。
- 「絞り込み」の3つの欄でも、同じ書き方が使えます。

### 絞り込み(項目ごとに検索する)
「絞り込み」ボタンを押すと、検索欄の下に3つの欄が出ます。

| 欄 | 探す場所 |
|---|---|
| 見出し語・読み | 見出し語と読みだけ |
| 意味 | 意味だけ |
| タグ | タグだけ(複数書くと、すべてを含む語に絞ります) |

検索欄と併用すると、すべての条件を満たす語だけが出ます。もう一度「絞り込み」を押すと、欄を閉じて条件を消します。

### タグの一覧
「絞り込み」のタグの欄の右にある「一覧…」を押すと、使われているタグと、そのタグが付いた語の数が一覧で表示されます。

- 上の欄に文字を入れると、その文字を含むタグだけに絞れます。
- タグに **チェックを入れて「OK」**(または Enter)を押すと、チェックしたタグの **すべてが付いた語** に絞り込みます(タグの欄に `"タグ"` の形で入ります)。
- 「IT」と「it」のように、書き方だけが違うタグは、別々の行に表示されます。検索では同じタグとして扱われますが、下の「名前の変更」で1つにそろえられます。

#### タグの名前の変更と削除
タグの一覧で、タグの行を選んで(クリックして、色を付けて)から、ボタンを押します。

| ボタン | 動作 |
|---|---|
| 名前の変更… | そのタグが付いたすべての語で、タグの名前を変えます。**すでにあるタグの名前** にすると、そのタグにまとめられます(「it」を「IT」に変えると、1つのタグになります) |
| 削除 | そのタグを、すべての語から外します。語そのものは消えません |

- 対象は、検索する辞書に入っている、書き込める辞書の語です。参照のみの辞書の語は変えず、件数を知らせます。
- 変更した語は、更新日時が変わります。
- 直後なら、「元に戻す」で取り消せます。

### 候補の並ぶ順番
**検索しているとき** は、一致の度合いが高い順に並びます。

1. 見出し語(または読み)が、入力と完全に一致する語
2. 見出し語(または読み)が、入力で始まる語
3. 見出し語(または読み)に、入力が含まれる語
4. 意味やタグにだけ含まれる語

**何も入力していないとき** は、選んだ並び順になります([6. しおりと並び順](#6-しおりと並び順))。

## 4. 語を登録・編集・削除する

### 登録する
「＋ 新規登録」ボタン、または **Ctrl+N** で、登録の画面が開きます。

| 欄 | 説明 |
|---|---|
| 見出し語 | 必須 |
| 読み | 任意。ひらがな・カタカナなどで書きます。読みでも検索でき、並び順にも使われます |
| タグ | 任意。スペース・カンマ・読点で区切って、いくつでも書けます。先頭の `#` は自動で外します。右の「選ぶ…」で、すでにあるタグの一覧から選べます(同じタグを、違う書き方で付けてしまうのを防げます) |
| 意味 | 必須。改行できます。リンクや画像を書けます([意味の文中のリンク](#意味の文中のリンク)、[画像を表示する](#画像を表示する)) |
| 参照先 | 任意。1行に1つ([5. 参照先](#5-参照先リンク)) |
| 登録先の辞書 | 書き込める辞書が2つ以上あるときだけ表示されます |

**Ctrl+Enter** または「保存」で登録します。Tab キーで次の欄へ移れます。

> 検索して見つからなかった語は、そのまま Ctrl+N を押すと、見出し語に入った状態で登録の画面が開きます。

#### 同じ見出し語がすでにあるとき
見出し語を入力したとき、同じ見出し語の語がすでにあれば、欄のすぐ下に知らせが出ます(例:「同じ見出し語の語が、すでに 1 件あります。」)。

- 「その語を表示」を押すと、登録をやめて、すでにある語を表示します。
- そのまま保存することもできます。登録先の辞書に同じ見出し語があるときは、確認が1回出ます(既定は「いいえ」)。同音異義語のように、別の語として登録したい場合は「はい」を選んでください。
- 「同じ」かどうかは、検索と同じ規則で判定します(「ＡＰＩ」と「api」は同じ見出し語とみなします)。
- 編集の画面でも、見出し語をほかの語と同じに変えたときに、同じ確認が出ます。

> 判定は、画面に読み込んである内容で行います。共有の辞書で、ほかの人が直前に登録した語は、知らせに出ないことがあります。

### 編集する
候補リストで語を選び、次のいずれかを行います。

- **F2** または **Enter**
- 行をダブルクリック
- 本文の下の「編集」ボタン
- 右クリック →「編集…」

### 削除する
候補リストで語を選び、**Delete** キー、または「削除」ボタンを押します。確認の画面が出ます(既定は「いいえ」)。

**Ctrl+クリック** や **Shift+クリック** で複数の語を選ぶと、まとめて削除できます。確認の画面に、件数と先頭の数語が表示されます。

削除した直後なら、次の「元に戻す」で取り消せます。

### 直前の操作を元に戻す
登録・編集・削除・取り込みを行うと、画面の左下に **「元に戻す」** が表示されます(例:「元に戻す(3 件の削除)」)。クリックすると、確認のあと、その操作を取り消します。

- 候補リストの右クリックのメニューにも「元に戻す」が出ます。候補リストを選んでいるときは **Ctrl+Z** でも実行できます(検索欄にいるときの Ctrl+Z は、入力した文字の取り消しです)。
- 削除した語は、しおりも一緒に戻ります。
- 元に戻せるのは、**直前の1回だけ** です。次の操作をすると、前の操作は元に戻せなくなります。アプリを終了しても、元に戻せなくなります。
- 元に戻した操作を、やり直すことはできません。
- 共有の辞書で、ほかの人がその後に同じ語を変更または削除していた場合、その語は元に戻さず、件数を知らせます(ほかの人の変更を消さないためです)。

### コピーする
| 場所 | 操作 |
|---|---|
| 候補リスト | **Ctrl+C** で「見出し語(タブ)意味」をコピー。右クリックで、見出し語だけ・意味だけも選べます |
| 本文 | 文字を選択して **Ctrl+C**。右クリックで「コピー」「すべて選択」も選べます |
| 入力欄 | **Ctrl+C / Ctrl+V / Ctrl+A**、右クリックのメニュー(切り取り・コピー・貼り付けなど) |

## 5. 参照先(リンク)

語には、参照先をいくつでも付けられます。本文の最後に「参照先」としてまとめて表示され、クリックすると開きます。

登録・編集の画面の「参照先」欄に、**1行に1つ** 書きます。

```
公式サイト | https://www.sqlite.org/
https://ja.wikipedia.org/wiki/SQLite
設計メモ | \\server\share\docs\notes.txt
[[トランザクション]]
```

| 書き方 | 表示 | 開く先 |
|---|---|---|
| `https://example.com/` | URL そのまま | Web ページ |
| `表示名 \| https://example.com/` | 表示名 | Web ページ |
| `表示名 \| C:\docs\memo.txt` | 表示名 | ファイルやフォルダ |
| `[[語]]` | 語 | この辞書の中の、その語 |
| `表示名 \| word:語` | 表示名 | この辞書の中の、その語 |

**相対パス**(`docs\memo.txt` のように、ドライブ名やサーバー名から始まらないパス)は、**辞書ファイルのあるフォルダ** を基準にします。辞書と一緒にフォルダごと移しても、リンクが切れません。

### 意味の文中のリンク
意味の中に書いたものも、リンクになります。

| 書き方 | 表示 | 開く先 |
|---|---|---|
| `https://example.com/` | URL そのまま | Web ページ |
| `[[語]]` | 語 | この辞書の中の、その語 |
| `[表示名](https://example.com/)` | 表示名 | Web ページ |
| `[表示名](C:\docs\memo.txt)`、`[表示名](\\server\share\memo.txt)` | 表示名 | ファイルやフォルダ |
| `[表示名](.\docs\memo.txt)` | 表示名 | 辞書ファイルのあるフォルダから見た、ファイルやフォルダ |
| `[表示名](word:語)` | 表示名 | この辞書の中の、その語 |

- `[表示名](開く先)` をリンクとして扱うのは、開く先が上の形のとき(URL、`mailto:`、`word:`、ドライブ名やサーバー名から始まるパス、`.\` か `..\` で始まるパス)だけです。`funcs[0](x)` のような文は、書いたとおりに表示されます。
- 開く先に空白や日本語が入っていても構いません。
- 開くときの確認は、参照先と同じです([開くときの確認](#開くときの確認))。

### 画像を表示する
意味の中に `![説明](画像のパス)` と書くと、その位置に画像が表示されます。

```
全体の構成は、次の図のとおり。
![構成図](dictionary_pic\構成図.png)
```

- **「画像を追加…」を使うのが簡単です。** 登録・編集の画面の、意味の欄の右上にあります。画像を選ぶと、カーソルの位置に上の書き方が入ります(`[ ]` の間に、説明を書けます)。
  - 選んだ画像は、「保存」を押したときに、辞書ファイルと同じフォルダの **`<辞書のファイル名>_pic`** フォルダ(辞書が `dictionary.db` なら `dictionary_pic`)へコピーされます。キャンセルした場合は、コピーされません。
  - 同じ名前の画像がすでにあるとき、中身が同じならそれを使い、違えば `構成図-2.png` のように番号が付きます。
  - 辞書を共有フォルダに置いていれば、ほかの人にも同じ画像が表示されます。
- パスを自分で書くこともできます。PC の中のパス、共有フォルダのパス、相対パス(辞書ファイルのあるフォルダが基準)が使えます。
- 対応している形式は、PNG・JPEG・GIF(動きません)・BMP です。1枚 20MB まで、1つの語に 20 枚までです。
- 画像は、本文の幅に収まるように縮小されます(拡大はされません)。
- 画像をクリックすると、既定のアプリで開きます。マウスを置くと、左下にパスが表示されます。
- 画像を表示できないとき(ファイルが無い、形式が違う、大きすぎる)は、説明の文字がリンクとして表示されます。説明が無ければ、ファイル名が表示されます。
- **URL の画像は表示しません**(このアプリは、インターネットに接続しません)。説明の文字が、その URL へのリンクになります。
  - 同じ理由で、`file://…` のような形や、`\\サーバー@SSL\…` のように HTTP(WebDAV)でつながる形のパスも、自動では読み込みません(説明の文字がリンクになり、クリックすると、確認のうえで開きます)。ドライブに割り当ててあれば、そのドライブのパスで書けます。
- 検索の対象になるのは、説明の文字です。パスは対象になりません。

> 画像のファイルは、辞書ファイルとは別です。書き出し(JSON / CSV / TSV)にも、バックアップにも含まれません。辞書を別の場所へ移すときは、`<辞書のファイル名>_pic` フォルダも一緒に移してください。
> 語を削除しても、画像のファイルは消えません(「元に戻す」で語を戻したときに、画像も表示できるようにするためです)。

> 共有の辞書では、語を表示すると、その語に書かれた画像のパスへアクセスします。辞書に書き込める人が、信頼できる人であることを前提にしています。

### 別の語へ移動する
`[[語]]` のリンクをクリックすると、検索欄がその語に変わり、一致する語が選ばれます。その語が登録されていなければ、その旨が表示されます(そのまま Ctrl+N で登録できます)。

### 移動する前の語に戻る
リンクで別の語へ移動したあと、**Alt+←**(またはマウスの「戻る」ボタン)を押すと、移動する前の表示に戻ります。検索欄の内容と、選んでいた語が元に戻ります。

- リンクを続けてたどった場合は、たどった順に1つずつ戻れます(50回まで)。
- 戻れるのは、アプリを起動している間だけです。

### 開く先を確かめる
リンクの上にマウスを置くと、画面の左下に開く先が表示されます(例:「リンク先: https://www.sqlite.org/」)。表示名を付けたリンクでも、クリックする前に、どこへ飛ぶかを確かめられます。
この辞書の中の語へのリンクは、「リンク先: この辞書の「語」」と表示されます。

### 開くときの確認
| 開く先 | 動作 |
|---|---|
| Web ページ(http / https) | そのまま開きます |
| ファイル・フォルダなど | 開く前に確認します |
| 実行ファイル(`.exe` `.bat` `.lnk` など) | 強い警告を出します(既定は「いいえ」) |

共有の辞書には、ほかの人が登録したリンクも入ります。実行ファイルへのリンクは、登録した人と内容を信頼できる場合だけ開いてください。

**Ctrl+O** で、選んでいる語の最初の参照先を開けます。

## 6. しおりと並び順

### しおり
あとで見返したい語に、しおりを付けられます。

- 語を選んで、本文の下の「☆ しおり」ボタン、または **Ctrl+D** で付け外しします。
- しおりを付けた語は、候補リストに **★** が付きます。
- 候補リストの上の「★ しおり」ボタンを押すと、**しおりを付けた語だけ** を、**付けた順** に表示します。
- その状態で検索欄に入力すると、しおりの中を検索できます。
- もう一度「★ しおり」を押すと、元の表示に戻ります。

しおりは辞書のファイルではなく、自分の設定フォルダに保存されます。共有の辞書を使っていても、しおりは人ごとに別々です。

### 並び順
候補リストの上の「並び」ボタンで、何も検索していないときの並び順を選べます。選んだ並び順は、次に起動したときも使われます。

| 並び順 | 内容 |
|---|---|
| 見出し語順 | 下の表の順 |
| 更新が古い順 | 更新日時の古いものが上 |
| 更新が新しい順 | 更新日時の新しいものが上 |
| しおり追加順 | しおりの表示中だけ選べます |

**見出し語順** は、次の順に並びます。

| 順 | 対象 | 並べ方 |
|---|---|---|
| 1 | 数字で始まる語 | 見出し語の順 |
| 2 | 英字で始まる語 | アルファベット順(大文字小文字は区別しない)。読みを付けていても、見出し語の綴りで並べます |
| 3 | 日本語の語 | 五十音順。読みがあれば読み、無ければ見出し語そのもので並べます。ひらがなとカタカナは同じ扱いです |
| 4 | 読みの無い漢字の語 | 文字コードの順(五十音にはなりません) |

> 漢字の語を五十音順に並べたいときは、読みを付けてください。

## 7. 設定

「設定」ボタン、または **Ctrl+,** で開きます。「保存」を押すと反映されます。

### 全般
| 項目 | 説明 |
|---|---|
| 呼び出しホットキー | ほかのアプリを使っているときでも、このキーで辞書を呼び出せます(既定は Ctrl+Alt+D)。枠を選んでキーを押すと変更できます。BackSpace で無効にできます |
| ウィンドウに表示する名前 | ウィンドウのタイトルに表示する名前です(例: 社内用語集)。何の辞書かが一目で分かります。書いたとおりに表示されます。空にすると「MyDictionary」と表示されます |
| 配色 | 画面の色です。「明るい」(既定)、「暗い」、「Windows の設定に合わせる」から選びます。**変更は、次に起動したときから反映されます。** くわしくは [配色(暗い画面)](#配色暗い画面) |
| 閉じるボタンや Esc で終了せず、トレイに隠して常駐する | オンにすると、閉じても終了せず、タスクバー右下のトレイに残ります。終了は、トレイのアイコンを右クリック →「終了」 |
| 共用フォルダで運用する | この設定ファイルを複数人で使うときにオンにします。くわしくは [10. 共有フォルダで複数人が使う](#10-共有フォルダで複数人が使う) |

> ホットキーは、アプリが起動している間だけ使えます。ホットキーで呼び出したい場合は、トレイに常駐する設定をオンにしてください。

### 配色(暗い画面)
設定の「配色」で、画面の色を選べます。ボタンを押すと、3つの中から選ぶメニューが出ます。

| 選択 | 動作 |
|---|---|
| 明るい | 白い地に黒い文字(既定) |
| 暗い | 暗い地に明るい文字 |
| Windows の設定に合わせる | Windows の「設定 → 個人用設定 → 色」で選んだ、アプリの色に合わせます(Windows 11 では「モードを選ぶ」、Windows 10 では「既定のアプリ モードを選択します」)。Windows の側が暗い色なら暗く、明るい色なら明るくなります |

- **「保存」を押しても、すぐには変わりません。アプリを終了して、次に起動したときから変わります。** トレイに常駐させている場合は、トレイのアイコンを右クリック →「終了」で、いったん終了してください。
- 「Windows の設定に合わせる」は、起動したときの Windows の設定で決まります。起動した後で Windows の設定を変えた場合も、次に起動したときから変わります。
- 暗い配色のときは、意味の中の画像の、透明な部分も暗い地の色になります。黒い線で描いた図は、見えにくくなることがあります(図に白い背景を付けておくと、どちらの配色でも読めます)。

暗い配色でも、次のところは Windows が描くため、**明るい色のまま**になることがあります。

| ところ | 説明 |
|---|---|
| 確認やエラーの知らせ(「削除しますか?」など)、取り込み方を選ぶ画面 | Windows の部品で、色を変えられません。明るい色のままです |
| ファイルを選ぶ画面 | Windows が表示します。Windows 側の対応しだいです |
| メニュー(右クリック、「並び」など)、スクロールバー、一覧の選んだ行の色、登録先の辞書を選ぶ欄 | Windows 10(バージョン 1809 以降)と Windows 11 では暗くなります。それより古い Windows では、明るい色のままです |

> 設定を共有している場合([10. 共有フォルダで複数人が使う](#10-共有フォルダで複数人が使う))は、配色も全員に同じ値が使われます。人によって好みが分かれるときは、「Windows の設定に合わせる」にしておくと、それぞれの PC の Windows の設定に従います。

### Windows の起動と同時に常駐させる
1. 設定で「トレイに隠して常駐する」をオンにします。
2. `Win + R` を押し、`shell:startup` と入力してフォルダを開きます。
3. `MyDictionary.exe` のショートカットを、そのフォルダに作ります。
4. ショートカットのプロパティを開き、「リンク先」の末尾に ` --background` を付け足します。

### 辞書
辞書の追加・削除・並べ替え、名前とパスの変更、参照のみの指定、取り込み・書き出しができます。くわしくは次の章を参照してください。

設定の画面の左下に、アプリの版と、いま使っている設定ファイルの場所が表示されます。自分の PC の設定か、共有フォルダの設定かを、ここで確かめられます。

### ライセンス情報
設定の画面の左下にある「ライセンス情報」をクリックすると、別の画面で次の内容を確認できます。

- このアプリのライセンス(MIT License)
- このアプリが使用しているオープンソースソフトウェアの一覧と、それぞれのライセンスの全文

「すべてコピー」で、表示している内容をクリップボードにコピーできます。「閉じる」または Esc で閉じます。同じ内容は、リポジトリの `THIRD-PARTY-NOTICES.txt` にもあります。

### 設定ファイルを直接編集する
設定は `MyDictionary.ini` に保存されています。トレイのアイコンを右クリック →「設定ファイルを開く」で編集できます。編集後は「設定ファイルを再読み込み」を選んでください。

```ini
[general]
hotkey = Ctrl+Alt+D      ; none で無効。Win キーを使う場合はここで指定(例: Win+Shift+D)
close_to_tray = false    ; true にすると、閉じてもトレイに常駐
sort = word              ; word / updated_asc / updated_desc
title = 社内用語集        ; ウィンドウに表示する名前。空なら MyDictionary
shared = false           ; 共用フォルダで運用するなら true
theme = light            ; 配色。light(明るい)/ dark(暗い)/ system(Windows の設定に合わせる)。書かなければ light

[dictionary.d1]          ; 先頭の辞書が、既定の登録先
name = メイン
path = dictionary.db     ; 相対パスは、この設定ファイルのあるフォルダが基準

[dictionary.d2]
name = 共有
path = \\server\share\dict\team.db
readonly = true          ; 参照のみ
```

### 持ち運んで使う(ポータブル)
`MyDictionary.exe` と同じフォルダに `MyDictionary.ini` があれば、そちらが使われます。辞書のパスを相対パスにしておけば、フォルダごと USB メモリなどで持ち運べます。

## 9. 取り込みと書き出し

設定の「辞書」で辞書を選び、「取り込む…」「書き出す…」を押します。

### 書き出す(JSON / CSV / TSV)
選んだ辞書のすべての語を、ファイルに書き出します。保存の画面の「ファイルの種類」で、形式を選びます(ファイル名に `.json` `.csv` `.tsv` を付けて指定することもできます)。

| 形式 | 向いている使い方 |
|---|---|
| JSON | 控え(バックアップ)、別の辞書への移し替え。内容がそのまま保たれます |
| CSV | Excel で開いて、一覧で見直す・まとめて直す |
| TSV | タブ区切りのテキストとして扱う |

どの形式にも、見出し語、読み、意味(改行もそのまま)、タグ、参照先、更新日時が入ります。書き出したファイルは、「取り込む…」でそのまま取り込めます。

CSV と TSV には、最後に **「管理用」の列** が付きます。どの語かを見分けるための番号が入っているので、**変えないでください**(下の「上書きする」で使います)。

> しおりは書き出しに含まれません。

### 取り込む(JSON / CSV / TSV)
ファイルの種類は、自動で見分けます。取り込む前に確認の画面が出るので、**同じ見出し語の語がすでにあるときの扱い** を選びます。それぞれを選んだときに何件が追加・上書きされるかも、同じ画面に表示されます。

| 選択 | 動作 |
|---|---|
| 両方残す(これまでの動作) | 見出し語と意味が両方同じ行だけ飛ばし、ほかは追加します。同じファイルを取り込み直しても増えません |
| ファイルの内容で上書きする | 同じ語を、ファイルの内容で置き換えます(下記) |
| 見出し語がすでにある語は取り込まない | 辞書に無い見出し語の行だけを追加します |

- 途中で失敗した場合、辞書は変更されません。
- 取り込みは、直後なら **元に戻せます**([直前の操作を元に戻す](#直前の操作を元に戻す))。

#### 上書きする(書き出して、直して、取り込む)
辞書を CSV に書き出し、Excel などで直してから、「上書きする」で取り込むと、直した内容を辞書に反映できます。

- **どの語かは、「管理用」の列の番号で見分けます。** 見出し語の誤字を直しても、同じ見出し語の語が複数あっても、正しい語が書き換わります。
- **書き出した後に、辞書の側で変更された語は、上書きしません。** ほかの人の変更を消さないためです。結果の画面に、その語が表示されます。
- 内容が同じ語は、何も変えません(更新日時も変わりません)。
- **列があって中身が空の項目は、空にします。** 列そのものが無い項目(たとえば、読みの列の無い表)は、今の値を残します。
- 表から行を消しても、辞書の語は消えません。
- 表に足した行(「管理用」が空の行)は、見出し語で照合します。辞書にもファイルにも、その見出し語が1件だけなら上書きし、辞書に無ければ追加します。どちらかに複数あるときは、どれを上書きするか決められないので、追加として扱います。
- 上書きした語の番号(しおりの対象)は変わりません。更新日時は、取り込んだ時刻になります。

確認の画面の「上書きの詳細を表示」で、上書きされる語(見出し語が変わる場合は「前 → 後」)を先に確かめられます。

> **Excel で開くときの注意**: Excel は、`-` や `=` で始まる値、`0123` や `1-2` のような値を、数式・数値・日付に変えてしまうことがあります。その状態で保存して上書きすると、見出し語などが変わってしまいます。確認の画面の「上書き n 件」が、自分で直した数より多いときは、取り込まずに「上書きの詳細」を確かめてください。取り込んでしまった場合は、直後なら「元に戻す」で取り消せます。

#### JSON
「書き出す…」で作られる形式です。自分で書く場合は、`word` と `meaning` があれば取り込めます。

```json
[
  { "word": "一期一会", "reading": "いちごいちえ", "meaning": "一生に一度の出会い。", "tags": ["四字熟語"] },
  { "word": "apple", "meaning": "りんご。\n赤い果物。" }
]
```

書き出した JSON には、語の番号(`id`)と更新日時(`updated_at`)が入っています。「上書きする」では、CSV の「管理用」の列と同じように、これで語を見分けます。

#### CSV / TSV
Excel で作った表を、そのまま取り込めます。

- **1行目に列名を書く**と、列名で対応づけます(順番は自由)。

  | 列名 | 別の書き方 |
  |---|---|
  | 見出し語 | 単語、語、word |
  | 意味 | 説明、meaning |
  | 読み | よみ、ふりがな、reading |
  | タグ | tag、tags |
  | 参照先 | リンク、link、url |
  | 管理用 | (書き出したファイルに付いている列。自分で作る表には不要です) |

- 列名の行が無いときは、左から **見出し語、意味、タグ、参照先、読み** の順とみなします。見出し語と意味以外は省略できます。
- 文字コードは、UTF-8・UTF-16・Shift_JIS(日本語版 Excel の「CSV」)を自動で見分けます。
- セルの中の改行や、カンマを含む値も、Excel の出力のままで取り込めます。
- TSV で改行を入れたいときは `\n` と書きます(`"…"` で囲んだ値と、CSV では、`\n` は書いたとおりの文字として扱います)。

`sample/sample.tsv` と `sample/sample2.tsv` が、取り込める TSV の見本です。

## 10. 共有フォルダで複数人が使う

辞書のファイルを共有フォルダに置けば、複数の人で同じ辞書を使えます。

> **大切なこと**: 辞書の保存に使っている SQLite は、共有フォルダ上での同時書き込みを完全には保証できません。まれにファイルが壊れる可能性があります。このアプリは、壊れにくく、壊れても戻せるように工夫していますが、**壊れないことを保証するものではありません**。大事な辞書は、定期的に書き出して、別の場所にも保存してください。

### 設定も共有する(配るだけで、同じ辞書が見えるようにする)
辞書だけでなく設定ファイルも共有フォルダに置くと、利用する人は、起動するだけで同じ辞書が見えます。辞書を登録してもらう手間が要りません。

1. 共有フォルダに、`MyDictionary.exe`、`MyDictionary.ini`、辞書のファイルを、同じフォルダに置きます。
2. `MyDictionary.ini` に、辞書と、次の2つを書きます(設定の画面からも指定できます)。

   ```ini
   [general]
   title = 社内用語集     ; ウィンドウに表示する名前
   shared = true          ; 共用フォルダで運用する

   [dictionary.d1]
   name = 用語集
   path = dictionary.db   ; この設定ファイルと同じフォルダの辞書
   ```

3. 利用する人は、共有フォルダの `MyDictionary.exe` を起動します(ショートカットを配ると便利です)。

実行ファイルと同じフォルダに `MyDictionary.ini` があると、自分の PC の設定ではなく、そちらが使われます。

**「共用フォルダで運用する」をオンにすると、次のようになります。**

| 項目 | 動作 |
|---|---|
| しおり | 使えなくなります(ボタンが表示されません)。しおりは設定と同じ場所に保存されるため、複数人で同時に書き込むと壊れるおそれがあるからです |
| 並び順 | 変えても保存されません(その起動中だけ有効)。次に起動したときは、設定ファイルに書かれた並び順に戻ります |
| 設定の「保存」 | 「全員に反映されます」という確認が出ます |

> 設定ファイルを勝手に変えられたくない場合は、共有フォルダの `MyDictionary.ini` を、Windows の機能で読み取り専用にしてください。
> ホットキーと「トレイに隠して常駐する」、配色も、共用の設定ファイルに書かれた値が全員に使われます。配色は、`theme = system`(Windows の設定に合わせる)にしておくと、それぞれの PC の設定に従います。

### このアプリが行っていること
書き込み(登録・編集・削除・取り込み)のたびに、次の手順を踏みます。

1. ほかの人が書き込み中なら、最大5秒待ちます。
2. 書き込む前に、ファイルが壊れていないか検査します。壊れていたら書き込みません。
3. 直前の状態を、**自分の PC** に保存します。
4. 書き込みます。
5. もう一度検査し、壊れていたら、3 で保存した状態に **自動で戻します**。
6. 検査に通った最新の状態も、自分の PC に保存します。

このほか、次の動作をします。

- **ほかの人の変更を取り込む**: ウィンドウを前面に出したとき、ファイルが変わっていれば自動で読み直します。
- **編集の衝突を知らせる**: 自分が開いた後に、ほかの人が同じ語を変更・削除していた場合は、上書きせずに知らせます。
- **壊れていたら復元を案内する**: 起動時や書き込み時にファイルが壊れていた場合、自分の PC のバックアップから復元するか確認します。

### バックアップの場所
`%LocalAppData%\MyDictionary\backup\<辞書名>-<記号>\`

| ファイル | 内容 |
|---|---|
| `latest.db` | 最後に書き込んだ直後の状態 |
| `pre-write.db` | 最後に書き込む直前の状態 |
| `gen-<数字>.db` | 10分ごとの世代バックアップ(10世代まで) |

### 使う人が気をつけること
- 全員が、同じ版のアプリを使ってください。自分より新しい版のアプリが書き込んだ辞書を開くと、起動したときに、画面の下段に「新しい版(2.05)のアプリでも使われています。アプリを更新してください」と表示されます(この知らせが出るのは、版 2.03 以降のアプリどうしです)。
- 大量の取り込みは、ほかの人が使っていない時間に行ってください。
- 「壊れている」と表示されたら、ほかの人にも知らせ、いったん全員が閉じてから復元してください。
- 参照するだけの人は、設定で「参照のみ」にしておくと安全です。

### 知っておいてほしい限界
- バックアップは、**その PC から書き込んだとき** に作られます。参照しかしていない PC には、復元に使えるバックアップがありません。
- 復元すると、その時点より後の変更(ほかの人の分を含む)は失われます。
- 書き込みのたびに検査とバックアップを行うため、大きな辞書を遅い回線で使うと、保存に時間がかかります(検索の速さには影響しません)。

| キー | 動作 |
|---|---|
| ↑ ↓ / PageUp / PageDown | 候補を移動(検索欄にいるままで使えます) |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+N | 新規登録 |
| F2 / Enter(候補リストで) | 編集 |
| Delete(候補リストで) | 削除 |
| Ctrl+D | しおりを付ける / 外す |
| Ctrl+Z(候補リストで) | 直前の操作(登録・編集・削除・取り込み)を元に戻す |
| Ctrl+O | 最初の参照先を開く |
| Alt+← | リンクで別の語へ移動したあと、移動する前の表示に戻る |

## 12. 困ったとき

### 起動できないとき
**「Windows によって PC が保護されました」と出る**
実行ファイルに署名が無いために出る警告です。「詳細情報」を押し、「実行」を選ぶと起動できます。

**「アプリケーション制御ポリシーによってこのファイルがブロックされました」と出る**
Windows 11 の Smart App Control が、署名のない実行ファイルを止めています。「Windows セキュリティ」→「アプリとブラウザー コントロール」→「Smart App Control」で状態を確認できます。
オフにすれば起動できますが、**一度オフにすると、Windows を再インストールしない限りオンに戻せません**。会社や学校の PC では、管理者に相談してください。

### ホットキーが効かない
- アプリが起動していますか。既定では、閉じると終了します。常駐させるには、設定の「トレイに隠して常駐する」をオンにしてください。
- ほかのアプリが同じキーを使っていると、登録できません(その場合、下段に表示が出ます)。設定で別のキーに変えてください。

### 閉じても終了しない / 終了してしまう
設定の「閉じるボタンや Esc で終了せず、トレイに隠して常駐する」で切り替えられます。常駐中の終了は、トレイのアイコンを右クリック →「終了」です。

### 語が一覧に出ない
- 検索欄や「絞り込み」の欄に、文字が残っていませんか。Esc で消せます。
- 「辞書」ボタンが「辞書: 1 / 3」のようになっていませんか。検索する辞書を絞っています。
- 「★ しおり」が押された状態になっていませんか。しおりを付けた語だけを表示しています。

### 漢字の語が、五十音順に並ばない
読みが登録されていない漢字の語は、位置を決められないため、最後にまとまります。読みを付けてください。

### 取り込んだら文字化けした
ファイルを、メモ帳などで「UTF-8」を選んで保存し直してから、もう一度取り込んでください。

### 「辞書ファイルが壊れています」と出た
画面の案内に従って、バックアップから復元できます。共有の辞書の場合は、ほかの人に知らせ、全員が閉じてから実行してください。
復元に使えるバックアップが無い場合は、最後に書き出した JSON ファイルから、新しい辞書に取り込み直してください。

### 「他の人が先にこの項目を変更または削除しました」と出た
自分が開いた後に、ほかの人が同じ語を変更しています。上書きはされていません。読み直された内容を確認して、必要ならもう一度編集してください。

### 設定をやり直したい
アプリを終了してから、`%AppData%\MyDictionary\MyDictionary.ini` を削除してください。次に起動したとき、初期の設定で作り直されます(辞書のファイルは消えません)。
