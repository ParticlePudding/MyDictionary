# MyDictionary テストチェックシート

完成前の確認の結果です。確認の方法は、次の3種類です。

| 記号 | 意味 |
|---|---|
| ○ / △ / — | 結果。○ = 期待どおり、△ = 一部だけ確認(注を参照)、— = 未確認 |
| 自動 | 自動テスト(`cargo test`、58件)で確認した |
| 実機 | 実行ファイルを実際に起動し、操作して確認した(下記の環境) |

## 確認した環境

| 項目 | 内容 |
|---|---|
| 対象 | `x86_64-pc-windows-gnu` 向けのリリースビルド(約1.7MB)。名前・データのフォルダ・アイコンを変え、サンプル追加のコマンドを削除した後(版 2.00)にも、初回起動・ウィンドウ名・バージョン情報・サンプルの取り込みを確認した |
| 自動テスト | Linux 上で `cargo test`。58件すべて成功 |
| 実機の操作 | Linux 上の Wine 9.0 と仮想ディスプレイ(Xvfb)。設定とデータをすべて消した初回起動の状態から、キーとマウスの操作を自動で送り、画面の撮影・辞書ファイルの中身・クリップボードの内容で結果を確かめた。一部の項目(2-11、3-5、3-16、5-5 など)は、完成直前の版で確認したもので、その後、該当する箇所は変更していない |
