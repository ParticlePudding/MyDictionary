# fastdict

Rust + windows-rs(Win32 標準コントロール)+ SQLite(静的リンク)の個人用辞書。
起動が速く、入力中に絞り込めることを重視しています。

## 使い方
電子辞書と同じく「入力 → 候補 → 本文」の流れです。起動(または呼び出し)直後から検索欄に入力できます。

- **上段**: 検索欄 / 辞書の選択 / 絞り込み / ＋ 新規登録 / 設定
- **左**: 候補リスト(見出し語と意味の抜粋。検索語は赤で強調)
- **右**: 本文(見出し語、タグ・辞書・更新日時、意味。検索語は赤で強調。文字を選択してコピー可)

| 操作 | 動作 |
|---|---|
| 文字を入力 | 見出し語・意味・タグを横断して絞り込み(スペース区切りで AND、大文字小文字無視、部分一致) |
| ↑ ↓ / PageUp / PageDown | 検索欄にいるまま候補を移動 |
| 絞り込み | 「見出し語 / 意味 / タグ」ごとの検索欄を表示(全体検索と AND。タグは複数指定で AND) |
| Ctrl+N | 新規登録(検索して見つからなかった語は、見出し語の初期値になる) |
| F2 / Enter / ダブルクリック | 選択した語を編集 |
| Delete | 選択した語を削除(Ctrl / Shift で複数選択可。確認あり) |
| Ctrl+F | 検索欄へ移動 |
| Ctrl+, | 設定 |
| Esc | 入力を消す → もう一度で隠す |
| ホットキー(既定 Ctrl+Alt+D) | どこからでも呼び出し |

終了はトレイアイコンの右クリックから。Windows 起動時に常駐させたい場合は、スタートアップフォルダ(`shell:startup`)に
`fastdict.exe --background` のショートカットを置いてください。

## 設定
右上の「設定」(Ctrl+,)またはトレイメニューから。

- ホットキーの変更(枠を選んでキーを押す)、閉じるボタンの動作
- 辞書の追加・削除・並べ替え・名前/パスの変更・参照のみの指定

設定は `fastdict.ini` に保存されます。場所は exe と同じフォルダ(あればそちら。ポータブル運用)、なければ `%AppData%\fastdict\`。
直接編集した場合は、トレイ右クリック →「設定ファイルを再読み込み」。

```ini
[general]
hotkey = Ctrl+Alt+D      ; none で無効。修飾キー(Ctrl/Alt/Shift/Win)必須
close_to_tray = true

[dictionary.d1]          ; 先頭の辞書が既定の登録先
name = メイン
path = dictionary.db     ; 相対パスは設定ファイル基準。%APPDATA% 等も可

[dictionary.d2]
name = 共有
path = \\server\share\dict\team.db
readonly = true          ; 参照のみ(登録・編集・削除不可)
```

## 共有フォルダで複数人が使う場合
SQLite はネットワーク共有上のロックを完全には信頼できないため、破損を「防ぎきる」ことはできません。
そのうえで、壊れにくく・壊れても戻せるように、書き込みのたびに次の手順を踏みます。

1. 書き込みロックを取得(他の人が書き込み中なら最大5秒待つ)
2. 書き込み前に整合性を検査(すでに壊れていたら書き込まず、復元を案内)
3. 直前の状態を **このPCのローカル** にスナップショット(`pre-write.db`)。10分に1回は世代バックアップも残す(10世代)
4. 1トランザクションで書き込み
5. ファイルを開き直して整合性を検査。壊れていたらスナップショットから **自動でロールバック**
6. 検査に通った最新の状態もローカルへ保存(`latest.db`)

バックアップの場所: `%LocalAppData%\fastdict\backup\<辞書名>-<パスのハッシュ>\`

そのほか:
- **他の人の変更の取り込み**: ウィンドウを前面に出したとき、ファイルが変わっていれば自動で読み直します。
- **編集の衝突**: 自分が開いた後に他の人が同じ語を変更/削除していた場合、上書きせずに知らせて読み直します。
- **起動時に壊れていた場合**: このPCのバックアップから復元するか確認します(復元すると、その時点より後の他の人の変更は失われます)。

限界: バックアップは「このPCから書き込んだとき」に作られます。参照しかしていないPCには復元元がありません。
また、復元の瞬間に他の人が書き込んでいる場合の競合までは防げません。重要な辞書は、共有フォルダ側の定期バックアップも併用してください。

## 計測
`fastdict.exe --bench [件数]` … 指定件数(既定10万)のテストDBを作り、読み込み・並べ替え・検索の時間を表示します(実データには触りません)。
